## How to Contribute

### Reporting Issues

Please use the appropriate issue template:
- **Bug Reports**: For issues with this integration
- **Feature Requests**: For new functionality ideas

**Important:** Do NOT report ArchiSteamFarm software bugs here. Use the [official ASF repository](https://github.com/JustArchi/ArchiSteamFarm/issues) instead.

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Test thoroughly
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

### Development Setup

1. Clone this repository
2. Copy `custom_components/asf_ha` to your Home Assistant config directory
3. Set up a test ASF instance
4. Test the integration

### Code Standards

- Follow PEP 8 style guidelines
- Use type hints
- Add docstrings
- Keep changes focused and minimal
- Update documentation for any user-facing changes

### Testing

- Test with different ASF versions
- Test with various Home Assistant versions
- Include screenshots for UI changes
- Test edge cases
